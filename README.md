# Get-MSP

---

## 🧭 What Is `Get-MSP`?

`Get-MSP` is an open-source toolkit for ethical, Git-native MSP automation.

It’s a PowerShell module, runner framework, and repo-first standard designed to help modern MSPs:
- Onboard infrastructure as code
- Run audits and drift detection automatically
- Eliminate lock-in
- Deliver transparent, portable systems to their clients

Everything we automate lives in GitHub. Everything we do is forkable, inspectable, and transferable. This isn’t just a toolkit — it’s a philosophy.

---

## ✨ Our Onboarding Philosophy

> We believe that modern IT infrastructure should be documented, automatable, and **ownable** by the client — not locked behind tools, dashboards, or contracts.

`Get-MSP` enables that by structuring every client’s setup as:
- A **dedicated GitHub repository** (private or public)
- Bootstrapped from an open template
- Backed by repo-scoped self-hosted runners
- Versioned configuration (DSC, Pester, policies)
- GitHub Actions workflows for inventory, compliance, remediation
- Built to be handed off — not held hostage

We don’t sell “centralized control.”  
We provide tools that **extend trust in consultancy and engineering**.

---

## 🔁 Handoff by Design

Repositories built with `Get-MSP` can be:
- Transferred to the client at any time
- Continued by another MSP or in-house IT
- Inspected and rebuilt without us

The runner setup, GitHub workflows, secrets, and audit logic **live with the client**, not with us. They own their repo — we help them run it well.
